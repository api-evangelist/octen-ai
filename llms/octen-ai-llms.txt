# Octen Docs

> Octen is the search infrastructure for AI: a real-time web search foundation that lets LLMs, agents, and apps reason with the world's latest information. These are the official technical docs for the Octen API platform.

Every page in this index is linked with a `.md` extension and returns clean Markdown, which is what agents should fetch instead of the HTML page. `https://docs.octen.ai/llms-full.txt` contains the full text of every page in a single file. Requests to any page URL with `Accept: text/markdown` also return Markdown.

## Search

- [Broad Search](https://docs.octen.ai/capabilities/broad-search.md): One question, many sub-queries, searched concurrently in a single call.
- [Web Search](https://docs.octen.ai/capabilities/web-search.md): Search the live web for ranked results with highlights and full content.
- [Image Search](https://docs.octen.ai/capabilities/image-search.md): Search the web for images by text query or reference image.
- [Video Search](https://docs.octen.ai/capabilities/video-search.md): Search the web for videos with ranked results and rich metadata.

## Extract and Models

- [Extract](https://docs.octen.ai/capabilities/extract.md): Turn any URL into clean, LLM-ready markdown or text.
- [Model Gateway](https://docs.octen.ai/capabilities/model-gateway.md): Frontier models behind one API key, with live web search built in.

## Embedding

- [Text Embedding](https://docs.octen.ai/capabilities/embedding.md): Turn text into semantic vectors with Octen's embedding models.
- [VL Embedding](https://docs.octen.ai/capabilities/vl-embedding.md): Encode text, images, and videos into one shared vector space.

## Applications

- [Answer](https://docs.octen.ai/capabilities/answer.md): Question to grounded, cited answer in one API call.
- [Deep Research](https://docs.octen.ai/capabilities/deep-research.md): Autonomous research agent that returns a cited, illustrated report.
- [Multimodal Chat](https://docs.octen.ai/capabilities/multimodal-chat.md): Chat answers interleaving text, images, and videos from live search.
- [Grounded Generation](https://docs.octen.ai/capabilities/grounded-generation.md): Generate images and videos grounded in real web references.

- [Broad Search API](https://docs.octen.ai/api-reference/broad-search.md): `POST /broad-search` parameters, request and response schema.
- [Web Search API](https://docs.octen.ai/api-reference/search.md): `POST /search` parameters, request and response schema.
- [Image Search API](https://docs.octen.ai/api-reference/image-search.md): `POST /image-search` parameters, request and response schema.
- [Video Search API](https://docs.octen.ai/api-reference/video-search.md): `POST /video-search` parameters, request and response schema.
- [Extract API](https://docs.octen.ai/api-reference/extract.md): `POST /extract` parameters, request and response schema.
- [Model Gateway API](https://docs.octen.ai/api-reference/chat-completions.md): `POST /v1/chat/completions`, `/v1/messages`, and `/v1/images/generations`.

- [Answer API](https://docs.octen.ai/api-reference/answer.md): `POST /answer` parameters, request and response schema.
