Octen (Octen.AI) is an AI-native web search and retrieval platform built for LLM applications and agents. Its REST API at api.octen.ai exposes Broad Search (multi-angle query decomposition), Web Search, News Search, Business Search, Image Search, Video Search, URL Extract, text and vision-language Embeddings, Answer, Deep Research, Grounded Generation, and an OpenAI/Anthropic-compatible Model Gateway, alongside a hosted MCP server (mcp.octen.ai), a CLI, a Python SDK, and published agent skills.

**Areas:** Search · Web Search · Artificial Intelligence · LLM · Embeddings · Content Extraction · Model Gateway · MCP · Agents · Deep Research · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Octen: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
